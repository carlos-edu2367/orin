# Task 8 — Documentar API e segurança

Crie apenas Markdown: `docs/architecture/700-api-security/701-api-sse.md` e `702-security.md`; sem endpoints ou código. API é Gateway adapter sem regra de negócio: comandos idempotentes para criar/controlar Execution, consultas de estado, SSE com cursor/reconexão/autorização, mapeamento de erro e nunca execução de agentes. Segurança: sessão server-side Redis, cookie HttpOnly, CSRF, PAT somente hash, autorização por escopo, AES-256-GCM para segredos e APP_MASTER_KEY externa, auditoria, isolamento user/workspace, revogação, rate/abuse limits. Operações sensíveis têm contexto completo. Cada RFC com seções obrigatórias, contratos tipados, eventos/fluxos, segurança/observabilidade/invariantes/futuro, links válidos.
