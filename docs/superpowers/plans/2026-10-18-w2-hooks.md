# W2 — Hooks (settings-layer hooks with the Claude Code protocol) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. Strict TDD: test → FAIL → implement → PASS → commit.

**Goal:** Run hooks declared in the 5 settings layers (`hooks` key, Claude Code schema) on the lifecycle events W0 emits, with the four handler types (`command`, `http`, `prompt`, `agent`), the Claude Code exit-code/JSON protocol, process-tree control, and apply their decisions at the points where they matter (PreToolUse, PermissionRequest, PostToolUse, UserPromptSubmit, SessionStart, Stop, PreCompact).

**Architecture:** A new package `agentos.hooks` (pure units: `processes`, `config`, `matching`, `protocol`, `runners`, `dispatcher`). `TurnSession.build_runtime` loads hook specs from `EffectiveSettings` and subscribes a `HookDispatcher` to the session's `LifecycleBus`. Emitters (toolset, runtime, session) read the `LifecycleDecision` the bus returns and act on it. Plugin hooks keep their existing confined executor and dispatch path (no double execution); unifying them happens in W5 with Claude Code plugin compatibility.

**Tech Stack:** Python 3.13 stdlib (`subprocess`, `ctypes` on Windows), `httpx` (already a dependency), pytest.

**Spec:** `docs/superpowers/specs/2026-10-18-orin-code-claude-code-full-parity-design.md` §5. Prior waves: W0/W1 plans, ledgers and reviews under `docs/superpowers/plans/` and `docs/superpowers/reviews/`.

## Global Constraints

- No new third-party dependencies.
- A hook never breaks a turn: every runner and the dispatcher catch everything; failure is a recorded, non-blocking outcome unless the hook sets `onFailure: "block"`.
- Repository (project/local) hooks only run when the workspace is trusted — already guaranteed because the W0/W1 loader drops `hooks` from untrusted repository files. Do not re-implement trust here.
- `disableAllHooks: true` (any layer that may set it) disables every settings hook. `allowManagedHooksOnly: true` read **only from managed layers** restricts hooks to managed ones.
- Command hooks run through the platform shell (`cmd.exe` on Windows, `/bin/sh` elsewhere) — they are user-authored configuration, exactly like Claude Code.
- Every subprocess tree is killed on timeout (Windows Job Object with `KILL_ON_JOB_CLOSE`; POSIX process group).
- Activity records for hook runs never include hook stdout/stdin (they may contain secrets): only event, source, a short label, status, exit code, duration, and a truncated block reason.
- Backend tests: `uv run pytest -q tests/unit` (baseline after W1: 2774 passed, 53 skipped). Frontend untouched in W2.
- One commit per task, message ending with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. **Never push.**

## Deviations from the master spec (intentional)

1. Plugin hooks are not migrated onto the new dispatcher in W2 (they keep the confined, no-shell executor and their 3 events). Migrating them now would either run them twice or break the plugin-hook contract tests; W5 unifies them together with `.claude-plugin` hooks.
2. Blocking semantics for `SubagentStop`, `TaskCompleted` and `ConfigChange` are not applied yet (the events fire and hooks run, but a block decision is only recorded). They need re-entry into subagent/task/settings flows that belong to W5/W3. `Stop`, `PreToolUse`, `PermissionRequest`, `PostToolUse`, `UserPromptSubmit`, `SessionStart` and `PreCompact` decisions are applied.
3. Hooks declared in skill/agent frontmatter (W5) and SDK-registered callbacks (W6) are out of scope.

```python
"""Run a shell command whose whole process tree dies with it on timeout."""

from __future__ import annotations

import os
import signal
import subprocess
from collections.abc import Mapping
from dataclasses import dataclass

MAX_OUTPUT_CHARS = 12_000


@dataclass(frozen=True, slots=True)
class ProcessResult:
    exit_code: int | None
    stdout: str
    stderr: str
    timed_out: bool
    error: str | None = None


class _WindowsJob:
    """A Job Object with KILL_ON_JOB_CLOSE: closing it kills every process inside."""

    def __init__(self) -> None:
        import ctypes
        from ctypes import wintypes

        kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
        kernel32.CreateJobObjectW.restype = wintypes.HANDLE
        kernel32.CreateJobObjectW.argtypes = [ctypes.c_void_p, wintypes.LPCWSTR]
        kernel32.SetInformationJobObject.restype = wintypes.BOOL
        kernel32.SetInformationJobObject.argtypes = [wintypes.HANDLE, ctypes.c_int, ctypes.c_void_p, wintypes.DWORD]
        kernel32.OpenProcess.restype = wintypes.HANDLE
        kernel32.OpenProcess.argtypes = [wintypes.DWORD, wintypes.BOOL, wintypes.DWORD]
        kernel32.AssignProcessToJobObject.restype = wintypes.BOOL
        kernel32.AssignProcessToJobObject.argtypes = [wintypes.HANDLE, wintypes.HANDLE]
        kernel32.TerminateJobObject.restype = wintypes.BOOL
        kernel32.TerminateJobObject.argtypes = [wintypes.HANDLE, wintypes.UINT]
        kernel32.CloseHandle.restype = wintypes.BOOL
        kernel32.CloseHandle.argtypes = [wintypes.HANDLE]

        class IoCounters(ctypes.Structure):
            _fields_ = [(name, ctypes.c_ulonglong) for name in (
                "ReadOperationCount", "WriteOperationCount", "OtherOperationCount",
                "ReadTransferCount", "WriteTransferCount", "OtherTransferCount",
            )]

        class BasicLimits(ctypes.Structure):
            _fields_ = [
                ("PerProcessUserTimeLimit", ctypes.c_longlong),
                ("PerJobUserTimeLimit", ctypes.c_longlong),
                ("LimitFlags", wintypes.DWORD),
                ("MinimumWorkingSetSize", ctypes.c_size_t),
                ("MaximumWorkingSetSize", ctypes.c_size_t),
                ("ActiveProcessLimit", wintypes.DWORD),
                ("Affinity", ctypes.c_size_t),
                ("PriorityClass", wintypes.DWORD),
                ("SchedulingClass", wintypes.DWORD),
            ]

        class ExtendedLimits(ctypes.Structure):
            _fields_ = [
                ("BasicLimitInformation", BasicLimits),
                ("IoInfo", IoCounters),
                ("ProcessMemoryLimit", ctypes.c_size_t),
                ("JobMemoryLimit", ctypes.c_size_t),
                ("PeakProcessMemoryUsed", ctypes.c_size_t),
                ("PeakJobMemoryUsed", ctypes.c_size_t),
            ]

        self._kernel32 = kernel32
        self.handle = kernel32.CreateJobObjectW(None, None)
        if not self.handle:
            raise OSError("CreateJobObjectW failed")
        info = ExtendedLimits()
        info.BasicLimitInformation.LimitFlags = 0x2000  # JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE
        if not kernel32.SetInformationJobObject(self.handle, 9, ctypes.byref(info), ctypes.sizeof(info)):
            kernel32.CloseHandle(self.handle)
            self.handle = None
            raise OSError("SetInformationJobObject failed")

    def assign(self, pid: int) -> bool:
        process = self._kernel32.OpenProcess(0x0100 | 0x0001, False, pid)  # SET_QUOTA | TERMINATE
        if not process:
            return False
        try:
            return bool(self._kernel32.AssignProcessToJobObject(self.handle, process))
        finally:
            self._kernel32.CloseHandle(process)

    def terminate(self) -> None:
        if self.handle:
            self._kernel32.TerminateJobObject(self.handle, 1)

    def close(self) -> None:
        if self.handle:
            self._kernel32.CloseHandle(self.handle)
            self.handle = None


def _decode(data: bytes | None) -> str:
    return (data or b"").decode("utf-8", errors="replace")[:MAX_OUTPUT_CHARS]


def _kill_tree(process: subprocess.Popen[bytes], job: _WindowsJob | None) -> None:
    if os.name == "nt":
        if job is not None:
            try:
                job.terminate()
            except OSError:
                pass
        try:
            subprocess.run(
                ["taskkill", "/PID", str(process.pid), "/T", "/F"],
                capture_output=True, timeout=10, check=False,
                creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0),
            )
        except (OSError, subprocess.SubprocessError):
            pass
    else:
        try:
            os.killpg(process.pid, signal.SIGKILL)
        except OSError:
            pass
    try:
        process.kill()
    except OSError:
        pass


def run_shell_command(
    command: str,
    *,
    cwd: str | None,
    env: Mapping[str, str],
    stdin_text: str,
    timeout_seconds: float,
) -> ProcessResult:
    options: dict[str, object] = {
        "shell": True,
        "cwd": cwd,
        "env": {str(key): str(value) for key, value in env.items()},
        "stdin": subprocess.PIPE,
        "stdout": subprocess.PIPE,
        "stderr": subprocess.PIPE,
    }
    if os.name == "nt":
        options["creationflags"] = subprocess.CREATE_NEW_PROCESS_GROUP | getattr(subprocess, "CREATE_NO_WINDOW", 0)
    else:
        options["start_new_session"] = True
    try:
        process = subprocess.Popen(command, **options)  # noqa: S602 - hooks are user-authored shell commands
    except (OSError, ValueError) as error:
        return ProcessResult(None, "", "", False, f"{type(error).__name__}: {error}")
    job: _WindowsJob | None = None
    if os.name == "nt":
        try:
            job = _WindowsJob()
            job.assign(process.pid)
        except OSError:
            job = None
    try:
        try:
            stdout, stderr = process.communicate(input=stdin_text.encode("utf-8"), timeout=max(0.1, float(timeout_seconds)))
        except subprocess.TimeoutExpired:
            _kill_tree(process, job)
            try:
                stdout, stderr = process.communicate(timeout=5)
            except (subprocess.TimeoutExpired, OSError, ValueError):
                stdout, stderr = b"", b""
            return ProcessResult(None, _decode(stdout), _decode(stderr), True)
        return ProcessResult(process.returncode, _decode(stdout), _decode(stderr), False)
    finally:
        if job is not None:
            job.close()
```

```python
"""Hooks declared under the ``hooks`` key of the settings layers (Claude Code schema)."""

from __future__ import annotations

import re
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any

from agentos.agentic.lifecycle import HookEvent
from agentos.settings import EffectiveSettings

HANDLER_TYPES = ("command", "http", "prompt", "agent")
DEFAULT_TIMEOUTS = {"command": 60, "http": 30, "prompt": 30, "agent": 120}
MAX_TIMEOUT = 600
MAX_HOOKS = 200
MAX_TEXT = 8_000
_PRECEDENCE = ("managed", "cli", "local", "project", "user")


@dataclass(frozen=True, slots=True)
class HookSpec:
    event: HookEvent
    matcher: str
    type: str
    source: str
    timeout: float
    command: str = ""
    url: str = ""
    headers: tuple[tuple[str, str], ...] = ()
    allowed_env_vars: tuple[str, ...] = ()
    prompt: str = ""
    model: str = ""
    run_async: bool = False
    on_failure: str = "ignore"
    status_message: str = ""

    def identity(self) -> tuple[Any, ...]:
        return (self.event, self.type, self.command, self.url, self.prompt, self.matcher)

    def label(self) -> str:
        if self.type == "command":
            return self.command[:120]
        if self.type == "http":
            return self.url[:120]
        return f"{self.type}: {self.prompt[:80]}"


@dataclass(frozen=True, slots=True)
class HookConfigError:
    source: str
    message: str


def _timeout(raw: Any, kind: str) -> float:
    if isinstance(raw, bool) or not isinstance(raw, (int, float)) or raw <= 0:
        return float(DEFAULT_TIMEOUTS[kind])
    return float(min(MAX_TIMEOUT, raw))


def _entry(event: HookEvent, matcher: str, source: str, raw: Any) -> HookSpec | str:
    if not isinstance(raw, Mapping):
        return "hook entry must be an object"
    kind = str(raw.get("type") or "command")
    if kind not in HANDLER_TYPES:
        return f"unsupported hook type '{kind}'"
    common = {
        "event": event, "matcher": matcher, "type": kind, "source": source,
        "timeout": _timeout(raw.get("timeout"), kind),
        "on_failure": "block" if raw.get("onFailure") == "block" else "ignore",
        "status_message": str(raw.get("statusMessage") or "")[:200],
    }
    if kind == "command":
        command = raw.get("command")
        if not isinstance(command, str) or not command.strip() or len(command) > MAX_TEXT:
            return "command hook needs a non-empty 'command' (at most 8000 characters)"
        return HookSpec(**common, command=command.strip(), run_async=raw.get("async") is True)
    if kind == "http":
        url = raw.get("url")
        if not isinstance(url, str) or not re.match(r"^https?://", url.strip(), re.IGNORECASE) or len(url) > 2048:
            return "http hook needs an http(s) 'url'"
        headers = raw.get("headers") if isinstance(raw.get("headers"), Mapping) else {}
        pairs = tuple((str(key)[:200], str(value)[:4000]) for key, value in headers.items() if isinstance(value, (str, int, float)))
        allowed = tuple(str(item) for item in raw.get("allowedEnvVars") or () if isinstance(item, str) and re.fullmatch(r"[A-Za-z_][A-Za-z0-9_]*", item))
        return HookSpec(**common, url=url.strip(), headers=pairs, allowed_env_vars=allowed)
    prompt = raw.get("prompt")
    if not isinstance(prompt, str) or not prompt.strip() or len(prompt) > MAX_TEXT:
        return f"{kind} hook needs a non-empty 'prompt'"
    model = raw.get("model") if isinstance(raw.get("model"), str) else ""
    return HookSpec(**common, prompt=prompt.strip(), model=model.strip()[:200])


def load_hook_specs(settings: EffectiveSettings) -> tuple[tuple[HookSpec, ...], tuple[HookConfigError, ...]]:
    if settings.get("disableAllHooks") is True:
        return (), ()
    layers = list(settings.layers)
    managed_only = any(layer.name == "managed" and layer.data.get("allowManagedHooksOnly") is True for layer in layers)
    ordered = sorted(layers, key=lambda layer: _PRECEDENCE.index(layer.name) if layer.name in _PRECEDENCE else len(_PRECEDENCE))
    specs: list[HookSpec] = []
    errors: list[HookConfigError] = []
    for layer in ordered:
        if managed_only and layer.name != "managed":
            continue
        declared = layer.data.get("hooks")
        if declared is None:
            continue
        source = layer.name
        if not isinstance(declared, Mapping):
            errors.append(HookConfigError(source, "'hooks' must be an object"))
            continue
        for event_name, groups in declared.items():
            try:
                event = HookEvent(str(event_name))
            except ValueError:
                errors.append(HookConfigError(source, f"unknown hook event '{event_name}'"))
                continue
            if not isinstance(groups, list):
                errors.append(HookConfigError(source, f"hooks.{event_name} must be a list"))
                continue
            for group in groups:
                if not isinstance(group, Mapping):
                    errors.append(HookConfigError(source, f"hooks.{event_name} entries must be objects"))
                    continue
                matcher = str(group.get("matcher") or "")
                if len(matcher) > 500:
                    errors.append(HookConfigError(source, "matcher is longer than 500 characters"))
                    continue
                if matcher and matcher != "*":
                    try:
                        re.compile(matcher)
                    except re.error:
                        errors.append(HookConfigError(source, f"invalid matcher '{matcher[:60]}'"))
                        continue
                entries = group.get("hooks")
                if not isinstance(entries, list):
                    errors.append(HookConfigError(source, f"hooks.{event_name}[].hooks must be a list"))
                    continue
                for raw in entries:
                    parsed = _entry(event, matcher, source, raw)
                    if isinstance(parsed, str):
                        errors.append(HookConfigError(source, parsed))
                    else:
                        specs.append(parsed)
    if len(specs) > MAX_HOOKS:
        errors.append(HookConfigError("settings", f"more than {MAX_HOOKS} hooks are declared; the rest are ignored"))
        specs = specs[:MAX_HOOKS]
    return tuple(specs), tuple(errors)
```

```python
"""Claude Code hook matchers."""

from __future__ import annotations

import re
from collections.abc import Mapping
from typing import Any

from agentos.agentic.lifecycle import HookEvent

MAX_TARGET = 500
MATCH_FIELDS: dict[HookEvent, str] = {
    HookEvent.PRE_TOOL_USE: "tool_name",
    HookEvent.POST_TOOL_USE: "tool_name",
    HookEvent.POST_TOOL_USE_FAILURE: "tool_name",
    HookEvent.PERMISSION_REQUEST: "tool_name",
    HookEvent.PERMISSION_DENIED: "tool_name",
    HookEvent.SESSION_START: "source",
    HookEvent.SESSION_END: "reason",
    HookEvent.PRE_COMPACT: "trigger",
    HookEvent.POST_COMPACT: "trigger",
    HookEvent.NOTIFICATION: "notification_type",
    HookEvent.SUBAGENT_START: "agent_type",
    HookEvent.SUBAGENT_STOP: "agent_type",
    HookEvent.CONFIG_CHANGE: "source",
    HookEvent.INSTRUCTIONS_LOADED: "memory_type",
    HookEvent.ELICITATION: "mcp_server_name",
    HookEvent.ELICITATION_RESULT: "mcp_server_name",
}
_WORD = re.compile(r"[A-Za-z0-9_\-]+")
_WORDS = re.compile(r"[A-Za-z0-9_\-]+(\|[A-Za-z0-9_\-]+)+")


def matcher_applies(event: HookEvent, matcher: str, payload: Mapping[str, Any]) -> bool:
    pattern = str(matcher or "").strip()
    if pattern in {"", "*"}:
        return True
    field = MATCH_FIELDS.get(event)
    if field is None:
        return True
    target = str(payload.get(field) or "")
    if _WORD.fullmatch(pattern):
        return target == pattern
    if _WORDS.fullmatch(pattern):
        return target in pattern.split("|")
    if len(target) > MAX_TARGET:
        return False
    try:
        return re.fullmatch(pattern, target) is not None
    except re.error:
        return False
```

```python
"""Claude Code hook protocol: exit codes, JSON control output, prompt/agent verdicts."""

from __future__ import annotations

import json
import re
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any

from agentos.agentic.lifecycle import HookEvent, LifecycleDecision

_CONTEXT_FROM_STDOUT = frozenset({HookEvent.SESSION_START, HookEvent.USER_PROMPT_SUBMIT, HookEvent.SUBAGENT_START})


@dataclass(frozen=True, slots=True)
class HookRun:
    exit_code: int | None
    stdout: str
    stderr: str
    timed_out: bool = False
    error: str | None = None


def _text(value: Any, limit: int) -> str | None:
    return value[:limit] if isinstance(value, str) and value.strip() else None


def _blocking(event: HookEvent, reason: str) -> LifecycleDecision:
    decision = LifecycleDecision(blocked=True, reason=reason[:4000])
    if event is HookEvent.PRE_TOOL_USE:
        decision.permission_decision = "deny"
    return decision


def decision_from_json(event: HookEvent, data: Mapping[str, Any]) -> LifecycleDecision:
    decision = LifecycleDecision()
    if data.get("continue") is False:
        decision.stop = True
        decision.stop_reason = _text(data.get("stopReason"), 2000) or "stopped by hook"
    message = _text(data.get("systemMessage"), 2000)
    if message:
        decision.system_messages.append(message)
    verdict = data.get("decision")
    if verdict == "block":
        blocked = _blocking(event, _text(data.get("reason"), 4000) or "blocked by hook")
        decision.blocked, decision.reason, decision.permission_decision = True, blocked.reason, blocked.permission_decision
    elif verdict == "approve" and event is HookEvent.PRE_TOOL_USE:
        decision.permission_decision = "allow"
    specific = data.get("hookSpecificOutput")
    if isinstance(specific, Mapping):
        context = _text(specific.get("additionalContext"), 10_000)
        if context:
            decision.additional_context.append(context)
        if event is HookEvent.PRE_TOOL_USE:
            permission = specific.get("permissionDecision")
            if permission in {"allow", "deny", "ask"}:
                decision.permission_decision = permission
                decision.reason = _text(specific.get("permissionDecisionReason"), 4000) or decision.reason
            updated = specific.get("updatedInput")
            if isinstance(updated, Mapping):
                decision.updated_input = dict(updated)
        elif event is HookEvent.PERMISSION_REQUEST:
            answer = specific.get("decision")
            if isinstance(answer, Mapping):
                if answer.get("behavior") in {"allow", "deny"}:
                    decision.permission_decision = answer["behavior"]
                updated = answer.get("updatedInput")
                if isinstance(updated, Mapping):
                    decision.updated_input = dict(updated)
                decision.reason = _text(answer.get("message"), 4000) or decision.reason
                if answer.get("interrupt") is True:
                    decision.stop = True
                    decision.stop_reason = decision.reason or "interrupted by hook"
        elif event is HookEvent.POST_TOOL_USE and "updatedMCPToolOutput" in specific:
            decision.updated_tool_output = specific["updatedMCPToolOutput"]
    return decision


def decision_from_command(event: HookEvent, run: HookRun, *, on_failure: str = "ignore") -> LifecycleDecision:
    if run.error or run.timed_out or run.exit_code is None:
        if on_failure == "block":
            return _blocking(event, run.error or ("hook timed out" if run.timed_out else "hook failed"))
        return LifecycleDecision()
    if run.exit_code == 2:
        return _blocking(event, run.stderr.strip() or "blocked by hook")
    if run.exit_code != 0:
        if on_failure == "block":
            return _blocking(event, run.stderr.strip() or f"hook exited with {run.exit_code}")
        return LifecycleDecision()
    text = run.stdout.strip()
    if text.startswith("{") and text.endswith("}"):
        try:
            data = json.loads(text)
        except ValueError:
            data = None
        if isinstance(data, Mapping):
            return decision_from_json(event, data)
        return LifecycleDecision()
    decision = LifecycleDecision()
    if text and event in _CONTEXT_FROM_STDOUT:
        decision.additional_context.append(text[:10_000])
    return decision


def parse_verdict(text: str) -> dict[str, Any] | None:
    found: list[dict[str, Any]] = []
    for match in re.finditer(r"\{[^{}]*\}", str(text or ""), re.DOTALL):
        try:
            value = json.loads(match.group(0))
        except ValueError:
            continue
        if isinstance(value, dict) and isinstance(value.get("ok"), bool):
            found.append(value)
    if not found:
        return None
    if len({item["ok"] for item in found}) > 1:
        return None
    return found[-1]


def decision_from_verdict(event: HookEvent, verdict: Mapping[str, Any] | None, *, on_failure: str = "ignore") -> LifecycleDecision:
    if not isinstance(verdict, Mapping) or not isinstance(verdict.get("ok"), bool):
        return _blocking(event, "hook gave no verdict") if on_failure == "block" else LifecycleDecision()
    if verdict["ok"]:
        return LifecycleDecision()
    return _blocking(event, _text(verdict.get("reason"), 4000) or "rejected by hook")
```

```python
from __future__ import annotations

import re
from pathlib import Path

MAX_FILE_BYTES = 256 * 1024
MAX_VARS = 100
MAX_VALUE = 8192
_LINE = re.compile(r"^(?:export\s+)?([A-Za-z_][A-Za-z0-9_]*)=(.*)$")


def read_env_file(path: Path) -> dict[str, str]:
    try:
        if not path.is_file() or path.stat().st_size > MAX_FILE_BYTES:
            return {}
        text = path.read_text(encoding="utf-8", errors="replace")
    except OSError:
        return {}
    values: dict[str, str] = {}
    for raw in text.splitlines():
        line = raw.strip()
        if not line or line.startswith("#"):
            continue
        match = _LINE.match(line)
        if match is None:
            continue
        key, value = match.group(1), match.group(2).strip()
        if len(value) >= 2 and value[0] == value[-1] and value[0] in {"'", '"'}:
            value = value[1:-1]
        values[key] = value[:MAX_VALUE]
        if len(values) >= MAX_VARS:
            break
    return values
```

```python
class HttpHookRunner:
    def __init__(self, client_factory: Callable[[], httpx.Client] | None = None) -> None:
        self.client_factory = client_factory

    @staticmethod
    def _interpolate(value: str, allowed: tuple[str, ...]) -> str:
        def replace(match: re.Match[str]) -> str:
            name = match.group(1) or match.group(2)
            return os.environ.get(name, "") if name in allowed else match.group(0)

        return re.sub(r"\$\{([A-Za-z_][A-Za-z0-9_]*)\}|\$([A-Za-z_][A-Za-z0-9_]*)", replace, value)

    def run(self, spec: HookSpec, payload: Mapping[str, Any]) -> HookRun:
        headers = {name: self._interpolate(value, spec.allowed_env_vars) for name, value in spec.headers}
        headers.setdefault("Content-Type", "application/json")
        try:
            client = self.client_factory() if self.client_factory else httpx.Client()
            with client:
                response = client.post(
                    spec.url, content=_payload_text(payload).encode("utf-8"), headers=headers,
                    timeout=spec.timeout, follow_redirects=False,
                )
                body = response.text[:MAX_HTTP_BODY]
        except (httpx.HTTPError, OSError, ValueError) as error:
            return HookRun(None, "", "", error=f"{type(error).__name__}: {error}"[:500])
        if 200 <= response.status_code < 300:
            return HookRun(0, body, "")
        return HookRun(1, "", f"HTTP {response.status_code}")


def _with_timeout(function: Callable[[], Any], timeout: float) -> Any:
    executor = ThreadPoolExecutor(max_workers=1)
    try:
        return executor.submit(function).result(timeout=timeout)
    except (FutureTimeout, Exception):  # noqa: BLE001 - a hook failure is a missing verdict
        return None
    finally:
        executor.shutdown(wait=False, cancel_futures=True)
```

```python
"""Bus subscriber that runs the hooks matching an event and merges their decisions."""

from __future__ import annotations

import logging
import time
from collections.abc import Callable, Mapping
from concurrent.futures import ThreadPoolExecutor
from typing import Any

from agentos.agentic.lifecycle import LifecycleDecision, LifecycleEvent

from .config import HookSpec
from .matching import matcher_applies
from .protocol import HookRun, decision_from_command, decision_from_verdict

logger = logging.getLogger(__name__)


class HookDispatcher:
    def __init__(
        self,
        specs: tuple[HookSpec, ...],
        *,
        command_runner=None,
        http_runner=None,
        prompt_runner=None,
        agent_runner=None,
        recorder: Callable[[Mapping[str, Any]], None] | None = None,
        max_workers: int = 8,
    ) -> None:
        self.specs = tuple(specs)
        self.runners = {"command": command_runner, "http": http_runner, "prompt": prompt_runner, "agent": agent_runner}
        self.recorder = recorder
        self.max_workers = max(1, int(max_workers))
        self._background = ThreadPoolExecutor(max_workers=4, thread_name_prefix="orin-hook-async")

    def close(self) -> None:
        self._background.shutdown(wait=False, cancel_futures=False)

    def _record(self, spec: HookSpec, status: str, exit_code: int | None, decision: LifecycleDecision, started: float) -> None:
        if self.recorder is None:
            return
        try:
            self.recorder({
                "hook_event": spec.event.value, "source": spec.source, "type": spec.type, "label": spec.label(),
                "status": status, "exit_code": exit_code, "blocked": bool(decision.blocked or decision.permission_decision == "deny"),
                "reason": (decision.reason or "")[:300], "duration_ms": int((time.monotonic() - started) * 1000),
            })
        except Exception:  # noqa: BLE001 - recording never breaks a hook
            logger.debug("hook recorder failed", exc_info=True)

    def _run_one(self, spec: HookSpec, payload: Mapping[str, Any]) -> LifecycleDecision:
        started = time.monotonic()
        runner = self.runners.get(spec.type)
        exit_code: int | None = None
        try:
            if runner is None:
                raise RuntimeError(f"no runner for {spec.type} hooks")
            if spec.type in {"command", "http"}:
                run = runner.run(spec, payload)
                exit_code = run.exit_code
                decision = decision_from_command(spec.event, run, on_failure=spec.on_failure)
                if run.timed_out:
                    status = "timeout"
                elif run.error or (run.exit_code not in (0, 2)):
                    status = "failed"
                else:
                    status = "ok"
            else:
                verdict = runner.run(spec, payload)
                decision = decision_from_verdict(spec.event, verdict, on_failure=spec.on_failure)
                status = "failed" if verdict is None else "ok"
        except Exception as error:  # noqa: BLE001 - a hook never breaks the turn
            logger.warning("hook %s failed: %s", spec.label(), error)
            decision = decision_from_command(spec.event, HookRun(None, "", "", error=str(error)[:300]), on_failure=spec.on_failure)
            status = "failed"
        if status == "ok" and (decision.blocked or decision.permission_decision == "deny"):
            status = "blocked"
        self._record(spec, status, exit_code, decision, started)
        return decision

    def __call__(self, event: LifecycleEvent) -> LifecycleDecision | None:
        payload = dict(event.payload)
        selected: list[HookSpec] = []
        seen: set[tuple[Any, ...]] = set()
        for spec in self.specs:
            if spec.event is not event.name or not matcher_applies(spec.event, spec.matcher, payload):
                continue
            key = spec.identity()
            if key in seen:
                continue
            seen.add(key)
            selected.append(spec)
        if not selected:
            return None
        for spec in selected:
            if spec.run_async:
                try:
                    self._background.submit(self._run_one, spec, payload)
                except RuntimeError:
                    pass
        blocking = [spec for spec in selected if not spec.run_async]
        if not blocking:
            return LifecycleDecision()
        if len(blocking) == 1:
            decisions = [self._run_one(blocking[0], payload)]
        else:
            with ThreadPoolExecutor(max_workers=min(len(blocking), self.max_workers), thread_name_prefix="orin-hook") as pool:
                decisions = list(pool.map(lambda spec: self._run_one(spec, payload), blocking))
        merged = LifecycleDecision()
        for decision in decisions:
            merged.merge(decision)
        return merged
```
