# Plugins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir que o Orin instale plugins no formato Claude Code (`plugin.json` + `skills/` + `agents/` + `.mcp.json`) a partir de um repositório GitHub, de um marketplace ou de uma pasta local — e que o próprio agente busque, inspecione e proponha essa instalação, com o usuário aprovando em um card no chat.

**Architecture:** Um novo pacote `src/agentos/plugins/` faz quatro coisas separadas e nessa ordem: **resolver** uma referência do usuário em um plano de busca, **buscar** o pacote para `data/plugins/<plugin_id>/<version>/`, **inspecionar** o conteúdo sem executar nada, e **ativar** registrando as contribuições nas portas que já existem (skills no `SkillLibraryService`, servidores MCP no `McpServerService`, subagentes numa tabela de templates). Nenhum código do plugin roda no processo do Orin: uma contribuição só existe como dado declarativo ou como servidor MCP, que já tem seu próprio isolamento por processo/rede.

**Tech Stack:** Python 3.12, `git` CLI para busca (shallow clone), SQLAlchemy Core + Alembic, o parser de SKILL.md que já existe em `agentos/skills/parser.py`, React 18 + TypeScript no cliente.

---

## Decisões de design (leia antes da Task 1)

Esta é a implementação pragmática da [RFC 901](../../architecture/900-extensibility/901-plugin-sdk.md). Os invariantes da RFC que este plano **mantém**: descoberta nunca executa payload; instalação, ativação e invocação são decisões separadas; versão publicada é imutável e identificada por digest; contribuição passa pela mesma validação que a implementação nativa; desativação não apaga histórico; metadata livre nunca controla autorização. O que este plano **não** faz, e por escolha: nenhum `PluginHost` com sandbox de processo, porque nenhuma contribuição do v1 é código executável.

| Decisão | Escolha | Porquê |
| --- | --- | --- |
| Formato | Claude Code (`.claude-plugin/plugin.json`) | O ecossistema existente (superpowers e afins) instala sem conversão. |
| Contribuições no v1 | `skills`, `mcpServers`, `agents` | São dados declarativos ou delegam isolamento ao MCP. |
| Contribuições recusadas no v1 | `hooks`, `commands` com script | `hooks` é código executando no host — exige a RFC 901 inteira. Instalar mesmo assim, **desativado**, com aviso visível. |
| Busca | `git clone --depth 1 --no-tags` para pasta temporária, depois move | Sem dependência nova; suporta qualquer host git; sem submódulos. |
| Skills do plugin | `SkillSource.PLUGIN` + `package_path` no disco | `Skill.package_path` e `read_skill_resource` já existem: o corpo e os `references/` são lidos preguiçosamente da pasta instalada. |
| MCP do plugin | Vira `pending_approval` no `McpServerService` | Instalar um plugin nunca ativa uma conexão de rede sozinho. |
| Aprovação | Card no chat com o resumo da inspeção | O usuário vê o que entra antes de entrar. |

### Estados do plugin

```
resolved ──► fetched ──► inspected ──► pending_approval ──► active ⇄ disabled
                                              │                 │
                                              └──► rejected     └──► removed
```

`inspected` é o estado em que o conteúdo já está no disco e lido, mas **nada** foi registrado no registry de skills nem no de MCP. `active` só é alcançado por aprovação explícita do usuário.

### Layout no disco

```
data/plugins/
  <plugin_id>/
    <version>/
      .claude-plugin/plugin.json
      skills/<name>/SKILL.md
      agents/<name>.md
      .mcp.json
      ...
  .marketplaces/<marketplace_id>/   # clone do repositório de marketplace
```

# src/agentos/plugins/models.py
"""Value types for plugin packages and their contributions.

Everything here describes a package that was read, never one that was run: a
manifest is untrusted input until the inspector has bounded it.
"""
from __future__ import annotations

import re
from dataclasses import dataclass, field
from enum import StrEnum

MAX_PLUGIN_ID_LENGTH = 64


def plugin_id_from_name(name: str) -> str:
    value = re.sub(r"-+", "-", re.sub(r"[^a-z0-9]+", "-", name.lower())).strip("-")
    if not value:
        raise ValueError("plugin name does not produce an identifier")
    return value[:MAX_PLUGIN_ID_LENGTH].rstrip("-")


class PluginState(StrEnum):
    INSPECTED = "inspected"
    PENDING_APPROVAL = "pending_approval"
    ACTIVE = "active"
    DISABLED = "disabled"
    REJECTED = "rejected"

    def can_transition_to(self, target: "PluginState") -> bool:
        return target in _TRANSITIONS[self]


_TRANSITIONS: dict[PluginState, frozenset[PluginState]] = {
    PluginState.INSPECTED: frozenset({PluginState.PENDING_APPROVAL, PluginState.REJECTED}),
    PluginState.PENDING_APPROVAL: frozenset({PluginState.ACTIVE, PluginState.REJECTED}),
    PluginState.ACTIVE: frozenset({PluginState.DISABLED}),
    PluginState.DISABLED: frozenset({PluginState.ACTIVE, PluginState.REJECTED}),
    PluginState.REJECTED: frozenset(),
}


@dataclass(frozen=True, slots=True)
class PluginRef:
    plugin_id: str
    version: str

    def __str__(self) -> str:
        return f"{self.plugin_id}@{self.version}"


@dataclass(frozen=True, slots=True)
class SkillContribution:
    skill_id: str
    name: str
    description: str
    relative_path: str


@dataclass(frozen=True, slots=True)
class McpServerContribution:
    slug: str
    display_name: str
    transport: str
    command: str | None
    args: tuple[str, ...]
    url: str | None
    secret_names: tuple[str, ...]


@dataclass(frozen=True, slots=True)
class AgentContribution:
    agent_id: str
    name: str
    role: str
    relative_path: str


@dataclass(frozen=True, slots=True)
class PluginInspection:
    ref: PluginRef
    display_name: str
    description: str
    author: str
    homepage: str | None
    package_digest: str
    skills: tuple[SkillContribution, ...] = ()
    mcp_servers: tuple[McpServerContribution, ...] = ()
    agents: tuple[AgentContribution, ...] = ()
    # Things the package declared that this host will not enable.
    warnings: tuple[str, ...] = ()

    @property
    def contribution_count(self) -> int:
        return len(self.skills) + len(self.mcp_servers) + len(self.agents)

    @property
    def is_installable(self) -> bool:
        return self.contribution_count > 0

    @property
    def requires_approval(self) -> bool:
        return self.is_installable


__all__ = [
    "AgentContribution", "McpServerContribution", "PluginInspection", "PluginRef",
    "PluginState", "SkillContribution", "plugin_id_from_name",
]
```

# src/agentos/plugins/manifest.py
"""Read plugin.json and .mcp.json as untrusted input.

A field this host does not know stays inert: it is never copied into a grant, a
path, or an argument. A hard-coded credential in .mcp.json is discarded — only
the variable's name survives, and the user supplies the value on approval.
"""
from __future__ import annotations

import re
from dataclasses import dataclass
from typing import Any, Mapping

from .models import McpServerContribution, plugin_id_from_name

SEMVER = re.compile(r"\d+\.\d+\.\d+(?:[-+][0-9A-Za-z.-]+)?")
MAX_TEXT = 1024
MAX_MCP_SERVERS = 16


class ManifestRejected(ValueError):
    """The manifest cannot identify a package this host would install."""


@dataclass(frozen=True, slots=True)
class PluginManifest:
    plugin_id: str
    display_name: str
    version: str
    description: str
    author: str
    homepage: str | None


def _text(value: Any, limit: int = MAX_TEXT) -> str:
    return str(value or "")[:limit]


def parse_plugin_manifest(payload: Mapping[str, Any]) -> PluginManifest:
    if not isinstance(payload, Mapping):
        raise ManifestRejected("plugin.json must be a JSON object")
    name = _text(payload.get("name"), 120).strip()
    if not name:
        raise ManifestRejected("plugin.json must declare a name")
    version = _text(payload.get("version"), 64).strip()
    if not SEMVER.fullmatch(version):
        raise ManifestRejected(f"plugin version '{version}' is not semantic versioning")
    author = payload.get("author")
    if isinstance(author, Mapping):
        author = author.get("name")
    homepage = _text(payload.get("homepage"), 512).strip() or None
    if homepage and not homepage.lower().startswith("https://"):
        homepage = None
    return PluginManifest(
        plugin_id=plugin_id_from_name(name),
        display_name=name,
        version=version,
        description=_text(payload.get("description")),
        author=_text(author, 120),
        homepage=homepage,
    )


def parse_mcp_config(payload: Mapping[str, Any]) -> tuple[McpServerContribution, ...]:
    servers = payload.get("mcpServers") if isinstance(payload, Mapping) else None
    if not isinstance(servers, Mapping):
        return ()
    built: list[McpServerContribution] = []
    for raw_slug, raw in list(servers.items())[:MAX_MCP_SERVERS]:
        if not isinstance(raw, Mapping):
            continue
        try:
            slug = plugin_id_from_name(str(raw_slug))[:32]
        except ValueError:
            continue
        url = _text(raw.get("url"), 2048).strip() or None
        command = _text(raw.get("command"), 512).strip() or None
        declared = _text(raw.get("type"), 16).strip().lower()
        transport = declared if declared in {"stdio", "http"} else ("http" if url else "stdio")
        if transport == "stdio" and not command:
            continue
        if transport == "http" and not url:
            continue
        env = raw.get("env") if isinstance(raw.get("env"), Mapping) else {}
        built.append(McpServerContribution(
            slug=slug,
            display_name=_text(raw.get("displayName") or raw_slug, 120),
            transport=transport,
            command=command if transport == "stdio" else None,
            args=tuple(_text(item, 512) for item in (raw.get("args") or []) if isinstance(item, str)),
            url=url if transport == "http" else None,
            # Names only: a value written into the package is not a credential
            # this host will ever forward.
            secret_names=tuple(str(key)[:120] for key in env),
        ))
    return tuple(built)


__all__ = ["ManifestRejected", "PluginManifest", "parse_mcp_config", "parse_plugin_manifest"]
```
