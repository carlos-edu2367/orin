## Summary verdict

**Not ready for W7 as is.** Five findings must be fixed first.

What holds:
- **The token is enforced.**
  - Only a caller holding this run's token can set `cli` options, read a CLI transcript or answer a host request. Each of those returned 403 without the token. A wrong bearer gets 401.
  - The token file is removed on `orin stop`.
  - The token never travels in argv or env, nor in the `--bg` record.
- **Managed MCP policy** (`deniedMcpServers` / `allowedMcpServers`) still filters `--mcp-config` and SDK servers.
- **`orin code mcp serve` holds.** It stays inside its folder, including through a junction. A repository allow rule grants nothing; the person's own rule does.
- **Callback hooks** are refused outside the cli layer.

What does not:
- **Wrong call approved.** An SDK host's `can_use_tool` can approve a different tool call than the one it was shown.
- **Killing `orin code` does not stop its turn.** That includes Ctrl-C and an SDK host's `close()`.
- **`purge`/`stop`/`rm` can kill an unrelated process tree** after the pid is reused.
- **Managed `disableBypassPermissionsMode` is ignored** by every new bypass route.
- **The SDK's default tools preset leaves the model with no tools.**

## Confirmed working / not findings

- **Non-CLI callers are refused, and the token is checked** (`$R/test_live_w6.py::test_l3…`):
  - a loopback call without the token is refused with 403 when it sends `cli` options, reads a transcript, or answers a host request;
  - a wrong bearer gets 401.
  - A loopback caller without the token can still create a `full_autonomy` turn (201). That is pre-existing and by design (the browser), so the token's extra reach is only the CLI's options. Any same-user process can read the token, which matches Claude Code's trust model.
- **The token is removed after `orin stop`** (`test_l6`, printed `removed`).
  - It is written owner-only (icacls with the SID; the System32 path is pinned) and compared in constant time.
  - It never goes into argv or env, the `--bg` record, `doctor` output, or `OrinClient.__repr__`.
  - The HTTP client uses `trust_env=False`, so no proxy sees it.
- **Managed MCP policy applies to `--mcp-config` and SDK servers**, strict or not (`$R/test_r11_cli_mcp_policy.py`: only `good` connects; `evil` is denied, the others are "not in allowedMcpServers").
- **`orin code mcp serve`** (`$R/test_r03_mcp_serve.py`, `$R/test_r03b_mcp_serve_rules.py`):
  - absolute paths, `..` and a junction to the parent are all refused (Read, Glob, Grep);
  - Write and Bash are refused in dontAsk mode;
  - a repository's own `allow` rule grants nothing;
  - the person's user rule `Bash(echo:*)` allows `echo` only.
- **Subagent permission modes from `--agents` / `initialize.agents` are capped** by the parent's mode (`session.py:2158-2159`).
- **`callback` hooks are refused outside the `cli` layer** (`hooks/config.py:79-86`).
- **A `type: sdk` server is refused from any file scope** (`mcp/file_config.py:126-130`).
- **SDK relays are unregistered when the turn closes.**
- **`kill_process_tree`'s bare `taskkill` is not taken from the current folder.** `$R/test_r12_planted_taskkill.py` planted a `taskkill.exe` in the current folder; Windows still ran System32's.
- **The SDK protocol shapes match `claude-agent-sdk 0.2.159`'s parser:**
  - `result` has `duration_ms`, `duration_api_ms`, `is_error`, `num_turns` and `session_id`;
  - `stream_event` has `uuid`, `session_id` and `event`;
  - the `initialize`, `can_use_tool`, `hook_callback` and `mcp_message` request and response envelopes match;
  - `--resume=<id>` and `--session-id=<id>` parse.
- **Every other flag the SDK sends parses**, except `--tools default` (R5), `--fork-session`, `--betas`, `--plugin-dir` and `--task-budget`. Those four are refused, as the ledger states.
- **Batch F, read and partly probed:**
  - the consolidation lock works across processes (the counter test fails without it);
  - LSP version filtering is in place;
  - NO_PROMPT_TOOLS / plan mode behave as described;
  - Setup fires before SessionStart (by code reading);
  - agent `effort` is gated on reasoning support.
