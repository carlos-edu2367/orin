# v0.1.4 provider fix release

The provider catalog SQLite timestamp fix and the installed-runtime improvements
are released as a patch version, v0.1.4. The release workflow requires the Git
tag and `desktop/package.json` version to match, then builds and hashes the
Windows archive before publishing `release.json` and `install.ps1`.

For a local frozen-release build, refresh the editable `agentos` installation
after changing `pyproject.toml`'s version. PyInstaller copies installed package
metadata, so stale environment metadata can make `orin.exe --version` lag the
manifest even when the source files have the new version.
