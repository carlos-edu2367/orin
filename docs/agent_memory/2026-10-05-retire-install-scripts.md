# Scripts de instalação aposentados (fase 4)

- Existe **uma** implementação de instalar/atualizar/desinstalar: `agentos.installation` (`updater.py`, `installer.py`, `uninstaller.py`). Não há mais lógica duplicada em PowerShell/Bash.
- `install.ps1` e `install.sh` (publicados na release como one-liners) agora têm ~60 linhas: baixam `OrinSetup.exe` / `OrinSetup-linux-x64` da release e rodam `--silent`. `-Version/--version` → `--to`; `-NoDesktopShortcut/--no-desktop-shortcut` → `--no-shortcut`; `-Uninstall/--uninstall` → `orin --uninstall`. No Windows usam `Start-Process -Wait` porque `OrinSetup.exe` é janela (o PowerShell não espera um exe GUI com `&`).
- `OrinSetup-linux-x64` sai do mesmo `packaging/setup.spec` (`scripts/build-setup.sh`, job Linux do `release.yml`). Sem tkinter/display cai em modo texto.
- Desinstalação em Python (`uninstaller.py`): remove comando, atalhos, PATH e chave do registro na hora; as pastas (instalação + estado + config) são apagadas por um helper destacado que espera o PID sair (caminhos via env/argv, nunca dentro do texto do script). Só apaga diretórios chamados `Orin/orin` que não são a home nem a raiz; pastas de dados customizadas são listadas como "mantidas". **Agora pede confirmação** (`--yes` para automação; sem terminal e sem `--yes` recusa) — antes apagava tudo sem perguntar. No Windows a config (`%APPDATA%\Orin`) agora também é removida (antes só `%LOCALAPPDATA%\Orin`).
- Removidos: `RuntimeProfile.installer` e o empacotamento dos scripts no runtime (`orin.spec`), `scripts/install-orin.ps1` (instalador de dev, 793 linhas: venv/npm/docker, obsoleto com o SQLite local) e `scripts/install-browser.ps1` (`orin browser install`). Dev: `uv sync`, build do frontend, `uv run orin`; `uv tool install --editable .` para o comando `orin` no PATH.
- Compatibilidade: releases já instaladas continuam atualizando pelo `install.ps1` que carregam consigo; o formato de `release.json` não mudou.
- Validado: `install.sh` baixando e rodando o `OrinSetup-linux-x64` congelado de um servidor local; helper de remoção com processo real (espera o PID e apaga, inclusive nome com `$(...)`). Não validado em Windows real: `install.ps1` fino, remoção do registro/PATH/atalhos.
