# Instalador gráfico (fase 3)

- `OrinSetup.exe` = PyInstaller onefile (≈8 MB sem tk) com `agentos.installation.setup_app` + tkinter. **Não** é NSIS: um stub NSIS só poderia "chamar o motor" se ele já estivesse na máquina, e numa primeira instalação não está. O instalador carrega o próprio motor (mesmo `Updater` do `orin update`) e baixa a release real em tempo de instalação.
- `installation/installer.py`: `Installer` = `Updater.run` + integração do SO (sétima etapa `integrate`). Windows: `orin.cmd` + `orin-desktop.ps1` em `%LOCALAPPDATA%\Orin\bin` (mesmos caminhos do `install.ps1`, então desinstalar/atualizar por qualquer caminho continua valendo), PATH do usuário via `winreg` + broadcast, atalhos via PowerShell/WScript.Shell (Desktop e Menu Iniciar), entrada em "Aplicativos instalados" (`HKCU\...\Uninstall\Orin`, `UninstallString` = `orin.exe --uninstall`). Linux: shim em `~/.local/bin` e `.desktop`.
- Rodar o setup por cima de uma instalação existente = atualização que também repara atalhos (`up_to_date` ainda re-executa `integrate`).
- Janela: `SetupModel` (puro, testado) transforma `UpdateEvent` em 7 passos + porcentagem ponderada (download = 62%); `SetupWindow` é a view tkinter (boas-vindas com pasta/atalhos/PATH, progresso, concluído, erro com "Tentar de novo"). Sem display/tkinter, `main()` cai no modo terminal. `--silent [--dir --to --no-shortcut --no-path]` para automação.
- Bug pego só ao rodar a janela (Xvfb + python3.12 com tk): `BooleanVar` criada antes do `Tk()`. Se `main()` não tivesse o fallback ela teria caído em silêncio no terminal — por isso `ORIN_SETUP_DEBUG=1` relança a exceção.
- Para o setup ficar leve, `launcher/ui.py` e `launcher/update_ui.py` foram movidos para `installation/console.py` e `installation/update_ui.py` (com reexportação no launcher): importar `agentos.launcher.*` puxa o launcher inteiro (httpx etc.).
- Build: `scripts/build-setup.ps1` (assina se `ORIN_CODESIGN_PFX`/`ORIN_CODESIGN_PASSWORD`), `release.yml` publica `OrinSetup.exe` ao lado de `install.ps1`. Sem certificado o SmartScreen avisa (README documenta o caminho "Mais informações → Executar assim mesmo").
- Validado aqui: janela sob Xvfb (capturas das 4 telas) e o binário Linux congelado instalando de um servidor HTTP local. NÃO validado: build Windows real, registro/PATH/atalhos no Windows, SmartScreen, tkinter no Python do runner.
