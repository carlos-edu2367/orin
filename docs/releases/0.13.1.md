# Orin `v0.13.1` — Notas de Versão

**Data:** 2026-11-22  
**Migrações Alembic:** nenhuma

---

## Correções

1. **Agendador não iniciava no app instalado (Windows) após atualizar para a `0.13.0`:**
   - Sintoma: a inicialização parava em *"Workers did not become ready. scheduler exited with code 1"*, com `ModuleNotFoundError: No module named 'agentos.persistence.postgres.memory_promotion'` em `scheduler.log`.
   - Causa: o portão de promoção de memória (`agentos.memory.promotion`) carrega seu backend via `importlib.import_module`, que o PyInstaller não detecta; o módulo ficava fora do executável.
   - Correção: `packaging/orin.spec` passa a incluir todos os submódulos de `agentos` (`collect_submodules("agentos")`), e um teste de regressão (`tests/test_packaging_hidden_imports.py`) impede que isso volte.
