# Release v0.2.5

## Conteúdo

- Correção: o botão "Atualizar catálogo" havia desaparecido da tela de configurações para Ollama e OmniRoute num refactor anterior da página de providers; o catálogo remoto ficava sem forma de ser atualizado pela UI.
- Correção: testar a conexão do Ollama Cloud sem uma chave de API retornava um erro genérico de "provider indisponível" (500) em vez de sinalizar a credencial ausente/rejeitada (422).
- Sincronizado `uv.lock` com a versão publicada do pacote `agentos` (estava desalinhado desde a v0.2.4).

## Validação

- Suíte frontend: 370 testes passando.
- Suíte Python (`tests/unit`): 1721 passando, 4 skipped.
- Build de produção frontend TypeScript/Vite concluído.
- Lint direcionado dos arquivos alterados concluído sem avisos.

## Publicação

A publicação dos artefatos Windows será feita pela GitHub Action acionada pela tag `v0.2.5`, que verifica a versão, constrói o pacote, valida o manifesto e publica o ZIP, `release.json` e `install.ps1`.
