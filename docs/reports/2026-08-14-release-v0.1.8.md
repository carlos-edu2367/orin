# Release v0.1.8

## Correções

- Corrige o stuttering do auto-scroll do chat enquanto o agente transmite texto e atividades de tools, inclusive ao iniciar uma nova mensagem.
- Mantém a viewport fixada sincronizada antes do paint e evita que a ancoragem automática do navegador dispute a posição do chat.
- Inclui a validação de publicação de Skills que estava no commit anterior ainda não enviado para `origin/main`.

## Validação

- Frontend: 268 testes passaram em 43 arquivos.
- Frontend: `npm run build` concluído.
- A publicação dos artefatos Windows será executada pelo workflow da tag `v0.1.8`.
