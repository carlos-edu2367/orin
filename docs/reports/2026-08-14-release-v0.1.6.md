# Release v0.1.6

## Correção

O comando `orin update` falhava porque o GitHub entrega assets de release como `application/octet-stream`. O Windows PowerShell recebia `release.json` como texto/bytes e a validação lia `$manifest.version` como vazio.

O instalador agora decodifica os dois formatos, remove BOM e desserializa o JSON explicitamente. O empacotador também passou a gravar manifests UTF-8 sem BOM.

## Validação

- Parser PowerShell validado contra o manifesto público: objeto JSON, versão e SHA-256 lidos corretamente.
- `install.ps1` e `scripts/package-release.ps1` sem erros de sintaxe.
- Suíte Python: 1237 aprovados, 3 ignorados.
- Build PyInstaller/Electron Windows concluído.
- Artefato: `Orin-0.1.6-windows-x64.zip`.
- SHA-256: `cf5f5e7ccdd03ddb22be182b75cab9b07cdad08b6346a97e606feeb00762b826`.

## Migração da instalação antiga

Instalações `0.1.4`/`0.1.5` carregam o instalador antigo localmente. Para a primeira atualização, executar o `install.ps1` da release `0.1.6` diretamente; após instalar a nova versão, `orin update` volta a funcionar normalmente.
