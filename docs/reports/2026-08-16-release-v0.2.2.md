# Release v0.2.2

## Conteúdo

- Indicador visual de uso do contexto no chat, com decomposição por system prompt, histórico, entrada atual, tools, Skills e MCPs.
- Compactação automática do contexto antes do trimming, preservando a solicitação atual e unidades atômicas de ferramentas.
- Modal para inputs acima de 16.000 caracteres, com envio opcional do conteúdo integral como `mensagem.txt`.
- Correções e melhorias já presentes no worktree foram incluídas nesta consolidação.

## Validação

- `uv lock --check`
- Testes Python focados de versões e contexto
- Testes React focados do chat e indicador de contexto
- Build frontend de produção
- `python -m compileall -q src`
- `git diff --check`

## Publicação

A publicação será feita pela GitHub Action acionada pela tag `v0.2.2`, que constrói o pacote Windows, verifica o manifesto e publica o ZIP, `release.json` e `install.ps1`.
