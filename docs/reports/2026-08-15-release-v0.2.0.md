# Release v0.2.0

## Destaques

- Plugins declarativos com busca, inspeção, proposta, aprovação explícita, ativação e remoção.
- Skills fornecidas por plugins registradas no catálogo do Orin após aprovação.
- Integrações MCP com configuração, descoberta, aprovação de credenciais e ferramentas aprovadas.
- Cartões de aprovação no chat para plugins e conexões MCP, preservando o estado durável `pending_approval` até uma decisão do usuário.
- Superfície de Settings para administrar plugins, marketplaces, Skills e servidores MCP.
- Correção do payload de atividade que fazia cartões de aprovação de plugins desaparecerem quando a contribuição excedia o limite genérico de eventos.

## Validação

- Testes focados do fluxo de aprovação: 35 passaram.
- `npm run build` do frontend concluído.
- O ambiente dev foi validado pela API e pela UI com o plugin `superpowers` pendente, cartão visível e 14 Skills listadas.

A publicação dos artefatos Windows será executada pelo workflow da tag `v0.2.0`.
