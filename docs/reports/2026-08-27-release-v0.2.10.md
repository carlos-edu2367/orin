# Release v0.2.10

## Correção

- Corrige o envio de uma nova mensagem em conversa vinculada a projeto.
- A falha ocorria após o primeiro turno porque `PostgresChatStore.create()` sombreava a tabela `projects` com um import local; no follow-up, a busca pelo workspace levantava `UnboundLocalError`.
- O chat preserva o workspace do projeto e enfileira a nova `Execution` normalmente.

## Evidência

- `python -m pytest -q`: 1819 testes aprovados; 69 integrações opcionais ignoradas.
- A regressão é coberta em `tests/unit/conversations/test_chat_store.py`.
