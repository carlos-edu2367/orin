# Release v0.2.8

## Conteúdo

- Novo cadastro de modelos manuais em cada provider, preservado durante a atualização dos catálogos.
- Modelos manuais ficam isolados por usuário e provider, incluindo modelos Ollama Cloud que não aparecem no catálogo remoto.
- A tela de providers permite adicionar, selecionar e remover modelos cadastrados pelo próprio usuário.
- A migração `0039_custom_provider_models` adiciona a persistência necessária para marcar modelos manuais.

## Validação

- Suíte Python: 1813 testes passando, 69 skipped.
- Suíte frontend: 390 testes passando.
- Build de produção frontend TypeScript/Vite concluído.
- Testes direcionados do scheduler: 7 testes passando.

## Publicação

A tag `v0.2.8` aciona a GitHub Action que verifica a versão, constrói o pacote Windows, valida o manifesto e publica o ZIP, `release.json` e `install.ps1`.
